# 稳定的免下载无广告天气预报

一个轻量的浏览器用户脚本（Userscript），把 [世界气象中心（北京）](https://www.wmc-bj.net) 的城市天气页
在手机上重排成真正可读的单列布局。原页面是按桌面栅格排版的，手机上只能整体缩小硬看；
这个脚本只做一件事——**把已有内容搬到该在的位置**：不改数据、不改功能、不请求任何外部资源。

> ⚠️ 仅适用于英文站 `www.wmc-bj.net/publish/weather/*`。
> 中文站 `www.nmc.cn` 请使用配套的 `nmc-cn-mobile-layout.user.js`。

## 效果

页面从上到下依次为：

**实况（日出日落弧线居中） → 7 天预报 → 逐小时预报 → 气候信息 → 原站搜索框**

- 顶部导航 / Logo 与页脚（地址、版权、Powered by、Maintenance）整块移除
- 产品、地图、预警、资讯等其余内容全部删除，只留预报本体
- 内容区 = 屏幕宽度，上限 480px 居中（电脑上打开也是干净的窄栏）

## 主要特性

- **补 `viewport`**：原页面缺少 meta viewport，手机会被缩放成桌面版，脚本自动补齐
- **7 天预报**：保持原列式排列，一屏固定显示 4 列，左右滑动看完整周
- **逐小时预报**：图例固定在左侧（120px），数据格子按可视区自适应——窄屏自动加宽一半（一屏约 2.7 列），左右滑动浏览；图例行与数据行强制等高，逐行严格对齐
- **日期跳转精确对齐**：点 7 天里的某天，逐小时视口会把该日第一列精确左对齐。同时修复了源站的固有 bug——源站按 672px/天 估算 `left` 必然偏移，且负 `left` 会把内容推出滚动区、跳完无法回划；本脚本改用 `scrollLeft` 自校正，并补校两次抵消站点异步重绘
- **Highcharts 自适应**：图表自动 `reflow`，宽度不足时提供横向滚动兜底
- **动态内容安全网**：页面数据为 AJAX 填充、切换日期会重建 DOM，脚本用轮询 + `MutationObserver` 保证重排只做一次、列宽随时跟上

## 安装

1. 安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net)（桌面）或 [Via](https://github.com/tobyweb/via)（安卓）
2. 打开最新版脚本（`wmc-mobile-layout-v1.5.1.js`）并导入
3. 访问任意城市天气页，如 `https://www.wmc-bj.net/publish/weather/...`

无 `GM_*` 依赖，`@grant none`，`document-end` 执行，可直接粘贴进任意脚本管理器。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `wmc-mobile-layout-v1.5.1.js` | 当前版本，仅匹配英文站 |
| `wmc-mobile-layout-v1.x.0.js` | 历史版本（1.0.0 → 1.5.0），按版本号递增 |
| `wmc-mobile-layout.user-v*.js` | 带 `.user.js` 后缀的安装版（1.3.2 / 1.4.1，1.4.1 起曾同时匹配 nmc.cn） |

版本演进要点：1.3.x 完成基础重排；1.4.x 拆分中英文站；1.5.0 起加入日期跳转精确对齐与源站回划 bug 修复，并把源站搜索框搬到页面底部。
